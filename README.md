# PickMe V3 FINAL

PickMe adalah bot Telegram yang menggabungkan fitur Feed dan Dating dalam satu platform.

## Fitur
- Registrasi member step-by-step
- Posting feed teks dan foto (limit harian)
- Swipe dating dengan like, comment, block
- Report & block member otomatis ke admin
- Preview profil member sebelum swipe
- Database PostgreSQL untuk semua data member

## Deploy
1. Set environment variable `BOT_TOKEN`
2. Jalankan `pip install -r requirements.txt`
3. Jalankan `python bot.py`
